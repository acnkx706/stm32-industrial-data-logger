# 已知边界与未做项

> 日期：2026-11-06
> 用途：把“这版不覆盖什么”写在明面上，避免 README/面试把设计目标说成实测。
> 原则：**没测就说没测，测了少数样本就说少数样本，不写“永不/100 次 0 损坏”。**

---

## 1. 存储与卡

1. **单卡**：全部 SD 数据来自同一张 4 GB FAT32 卡（3,956,801,536 B，32 KB 簇）。
   没有第二张卡做交叉验证；换卡行为只测了“无卡 / exFAT / 换回同一张卡”。
2. **卡健康只查过一次**：格式化后全容量写满 3.956 GB、拔插、读回 0 mismatch；
   这不等于“卡永远健康”，也没有测写入寿命、坏块增长、温度。
3. **物理坏卡/坏块未测**：EXP-03 的“坏卡”只指文件系统不可挂载（exFAT，`FR_NO_FILESYSTEM=13`）；
   没有人为制造坏块、没有用坏卡跑长时间。
4. **填充率只到 0% / 52% / 91.5%**：0% 是格式化后干净卡；52%/91.5% 是脏卡；
   “卡脏不脏”和“占用率”两个变量没有完全拆开。0/50/90 的软件填充测试没有做。
5. **942 ms 未定案**：只出现 1 次（91.5% + 刚灌 1.5 GB 后 7 分钟）；20 万次未复现；
   三个候选解释（卡内 GC / 未刷卷残留 / 计时窗口被抢占）都没有证明。
   不能写“已解决/已定位”。
6. **100k 分位数无效**：直方图桶 `uint16` 饱和，p90/p99=256 是假数；只引 avg/max。
7. **缓存容量没测满**：只测到拔卡 89 s 回写 89 条、exFAT 276 条；
   “全速率 63 分钟 / 降采样 1 条/秒 ~10.6 小时”是核算值，不是实测。
8. **掉卡期间降采样**：故障期只保留 1 条/秒，恢复后回写的是这 1 条/秒，不是全分辨率。
   这是设计取舍，不是“全量缓存”。

## 2. 掉电与故障注入

9. **掉电只做 8 次**（EXP-03 C 组）：8/8 进 App、0 回滚、每次丢 1 个在途批 2~6 行；
   给不出失败率/置信区间。不能写“100 次 0 损坏”。
10. **拔卡只做 6 次**（EXP-03 A 组）：6/6 不死机、6/6 恢复；代价 A 25 + B1 5 = 30 条 `no_buf`。
    样本 6 次，不能写“拔卡 0 丢失”。
11. **金副本保存窗口不是掉电安全**：单槽设计，保存时先擦镜像区、最后写头；
    保存中途掉电可能让旧备份失效。EXP-03 没有测这个窗口。
    另外：`app_ok` 失败后未重算；黑名单单槽；没有回退标记。
12. **没有 PVD / 超级电容 / FRAM**：掉电保护只有“每批 `f_sync` + IWDG + 安全关机握手”；
    不能承诺“掉电瞬间最后一批一定落盘”。
13. **没有卡检测脚（CD）**：拔卡靠下一次 I/O 失败发现，不是硬件中断；检测有延迟。
14. **W25 缓存灌满 / 坏项注入未做**：缓存环满了会覆盖最旧，超出部分是真丢；
    坏项跳过逻辑有代码，但没有做“灌满 + 坏项”实验。

## 3. 长跑与时间

15. **17 天里有 11 天干净窗口**（10-22~11-01，`storage_loss=0`）；
    10-18~10-20 早期文件有介质层异常（26101801.CSV 混入二进制垃圾）；
    不能写“17 天零丢失”。
16. **10-29 tick 台阶未定案**：10-29 前后有 tick/rtc 台阶，现有证据不足以归因。
17. **52 行残差未解释**：`16,133` 的四块拆分里还有约 52 行没逐条解释；
    34 文件口径是数字还原，未找到当时清单证实。
18. **时间基（EXP-04，2026-11-07）**：13.05 h 实测 `tick` **−1,227 ppm**、`RTC` **−10 ppm**（LSE）；
    10-28 19:45 UTC 有一次约 **1,800 ppm** 的渐变；11 月初又回到 **−1,215 ppm**（不是 −1,785）；
    **至少两次方向相反的变化，原因未定案**。`tick` 不能当长期秒表（约 −105 秒/天），`rtc` 可信。
    DISP 113 ms 仍是推算/未查。

## 4. 环境与验证范围

19. **没有 72 h soak / EMC / 高低温 / 振动**：全部是实验室台架，室温、USB 供电。
20. **没有网络模块 / 网络 OTA**：CBT6 到边界；下一版用协处理器（ESP32/4G）或 RCT6/F407。
21. **没有 P-MOS 断电重挂 SD**：PB10 被 OLED 占用后计划挪到 PA15；本版未做。
22. **没有第二张卡 / 0/50/90 填充率 / 100 次随机断电**：明确不做，写在这里，不再当待办。

## 5. 代码与协作

23. **代码大部分由 AI 生成**：作者负责架构约束、硬件、金副本规则、长跑、故障注入与验证；
    不声称“每一行手写”，也不删除 AI 痕迹。
24. **注释规范只按“读到哪里改到哪里”**：旧代码里还有 `★/✗/✓` 与旧数字，没有全量清理。
25. **证据矩阵/本文件是 2026-11-06 的版本**：后续实验若改变结论，先改原始报告，再回来改这两份。

**这版能证明“拔卡/掉电之后还活着、丢多少、能不能恢复”；不能证明“永不丢、工业级、100 次 0 损坏”。**
