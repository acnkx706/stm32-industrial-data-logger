## 2. 怎么用这张表

- **简历/面试只引 `[实测]`**；`[设计目标]` 必须带“按设计/按核算”；`[未定案]` 必须说“未定案”；`[未做]` 直接说没做。
- 每条 `[实测]` 都要能回答：**样本量、条件、单卡还是多卡、平静还是故障态**。
- 这条表不替代原始报告；有冲突时以原始报告为准，并回来改这张表。
