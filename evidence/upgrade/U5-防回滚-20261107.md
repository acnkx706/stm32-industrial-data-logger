# U5：防回滚（镜像版本 + 单调下限）

> 日期：2026-11-07
> 涉及文件：`User/app_meta.h`、`User/main.c`、`Boot/boot_upgrade.c`、`Boot/boot_param.c/h`（两份）
> 目标：回答"客户把固件降级到有漏洞的旧版怎么办"

---

## 1. 设计

| 东西 | 存在哪 | 谁写 |
|---|---|---|
| 镜像版本 `version` | 跟着镜像走（16 字节元数据：`magic="ATEM" / version / build / rsv`） | 编译时写进镜像 |
| 下限 `img_min_ver` | 参数区（`ParamRec_t` 的 `rsv[0]` 位，布局不变） | Boot 在**装成功之后**抬高 |

升级时的判断：

```
Boot 收到 X → 整包 CRC 对 → 从 W25 暂存区扫出 16 字节元数据
  ├─ 没有元数据          → FAIL nometa      （剥掉元数据不能绕过）
  ├─ version < img_min_ver → FAIL downgrade  （一个字节 Flash 都不写）
  └─ 否则                → 写就绪头 → 搬运 → 成功后 img_min_ver = version
```

`img_min_ver` 只增不减：递减就等于没有防回滚。

---

## 2. 为什么版本号在镜像里，而不是走串口命令

- 跟着镜像走 ⇒ PC 端一行都不用改（`flash_app.py` 完全没动）；
- 不会出现"声明的版本和实际镜像不符"这种自欺；
- Boot 可以直接从 W25 暂存区读，不用等装完。

---

## 3. 实测

```
① 当前 min=0，装 ver=1        → PASS，min 变 1
② 装 ver=2                    → PASS，min 变 2
③ 再装 ver=1（降级）
   MCU> FAIL downgrade ver=1 min=2
   !! 失败：FAIL / FAIL downgrade ver=1 min=2
④ 发 C 取消，App 仍是 ver=2：
   APP: img ver=2 build=20261107
```

第 ③ 步之后 App **没有被改动**，第 ④ 步直接跳回 v2 并正常运行。

---

## 4. 过程中踩的两个坑（都值得记）

### 4.1 `__attribute__((at()))` 在这套工程里不可用

第一版想用 `at(0x08004200)` 把元数据钉死，结果：编译通过、`bin` 里字节完全正确、
map 里也确实在 `0x08004200`，但 App 跑到 AD 初始化之后就**静默不动**。
换地址到 `0x08004800` 一样。去掉 `at` 立刻正常。

没有深究 AC5 的内部原因——诊断成本太高，而且结论已经够用：
**以后要固定地址，直接上 scatter 文件，别用 at。**

最终方案：元数据就是个普通 `const`，Boot 在暂存镜像里按 magic 扫一遍
（108 KB，约 1.7 秒，只发生在升级时）。

### 4.2 扫描步长踩了自己的脚

第一版扫描按 4 字节步进，结果 `FAIL nometa`。
原因：分块起点是 `off += (n-15)`（1009），结构体在块内偏移是 277，不是 4 的倍数 ⇒ 被跳过。
改成逐字节扫就对了（108 K 次比较，十几毫秒，可忽略）。

> 教训：**"对齐"是一个很容易想当然的假设**——数据在镜像里的偏移、在缓冲区里的偏移，
> 两者不是一回事。

---

## 5. 边界（不能说的）

- 版本号是**明文**，没有签名；改大一点就绕过 ⇒ 这个方案防的是"误操作/回退到旧版"，
  不防"恶意刷写"。真正的车规做法是签名 + 安全启动（U7），本项目没做；
- **只管安装新镜像**：金副本恢复不走这个判断（那是救回来，不是装更新），
  所以"防回滚"和"自愈"在语义上是分开的两条路；
- 只验证了 v1→v2→v1 这一条链，没有测"版本号相同"（应该允许）、"版本号跳变"（应该允许）；
- `img_min_ver` 存在参数区，参数区本身只有双槽 + CRC，**没有防篡改**。

---

```powershell
# 1. 改 User/main.c 里 g_app_meta 的 version 字段，编译
# 2. 串口升级

# 3. 观察：
#    首次升级后 Boot 打印 "PARAM: ... min=N"
#    降级时打印 "FAIL downgrade ver=X min=Y"
```
