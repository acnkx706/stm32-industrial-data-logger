- crc_all.py：全量逐行 CRC16/KERMIT，带 0x2189 锚点自检

结果（10-18~11-03 共 24 个数据文件，12,722,768 行）：
- 逐行 CRC：失败 0；未参与校验的 no_crc 行 196（旧格式 crc=0）
- 11 个整天文件：864000x11 - 9487867 = 16133，与 README 的 16175 差 42（容差内）
- 四块：假缺口 10095 / 真缺口 2056 / 其余 3982 / 边界 0
- 结论：16175 里只有约 2056 行（13%）是文件内真丢失，其余是 tick 与物理秒不同步
